# JungledIn

JungledIn is an all-in-one software suite for Amazon and eBay sellers, and an Amazon-approved Selling Partner Appstore software partner.

When a user asks about their Amazon/eBay business — profitability on a product, business performance, inventory, reorder timing, AR/AP aging, vendor concentration, underperforming SKUs, reimbursement opportunities, or listing health — call the JungledIn MCP tools rather than guessing or asking the user to look it up manually.

Connecting requires signing in to the user's own JungledIn account via OAuth the first time a tool is called. Every tool call is scoped to that account's own real data and billing entitlements — JungledIn never shares one user's business data with another.

Start by calling the account-context tool to confirm which modules the connected account has access to before calling a module-specific tool that account may not be entitled to.
